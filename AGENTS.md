# Android pilot APK delivery

When delivering an updated NMS pilot APK from this Windows workspace, copy the verified build to `G:\My Drive\Laptop-Praveen-TUF-A16`. Verify that the destination file matches the local build by SHA-256, then move superseded NMS APKs from the top level of that folder to its `Archive` subfolder. Use distinct filenames when versions would collide. Link to the current APK in the Drive folder when reporting delivery.
